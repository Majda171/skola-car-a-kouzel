# Baziliškova zkouška – Bradavice v453

Tato verze je integrovaná do školního webu. Odkaz v Tajemné komnatě vede na baziliskova-zkouska/index.html.

Školní žebříček tří nejlepších a 150 kolejních bodů za nový ověřený rekord vyžadují zvláštní SQL pro Supabase (není součástí veřejného ZIPu). Když RPC chybí, zůstává trénink bez bodové odměny. Kamenné ruiny jsou tréninkový režim.

Vzhled a ovládání vycházejí přímo z uživatelské hry v4.
